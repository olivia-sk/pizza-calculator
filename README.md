# Pizza Dough Calculator 🍕

A baker's-percentage pizza dough calculator. Pick a style and pizza size,
set your fermentation schedule, and get a full recipe with a step-by-step
timeline — for straight dough, poolish preferment, or sourdough starter.

## Features

- Doughball weight calculated from pizza diameter and style thickness factor
- Yeast (or starter) dose calculated from fermentation time and room
  temperature, with an optional cold ferment stage
- Simple mode picks salt, oil, sugar and starter % for you; Advanced mode
  (Settings) unlocks them
- Metric/imperial and light/dark, both switchable in Settings

## Getting Started

```bash
bun install
bun dev
```

Open [http://localhost:3000](http://localhost:3000).
